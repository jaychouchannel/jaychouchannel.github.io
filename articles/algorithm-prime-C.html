用 C 语言判断质数：方法与练习题

C
Jaychouchannel
2025-11-24

本篇介绍如何用 C 语言实现质数判断（Primality Test），从基础暴力算法到更高效的优化实现，并通过若干例题加深理解。

一、什么是质数

质数（prime）是大于 1 且仅能被 1 和自身整除的正整数。

二、最简单的判断方法（试除法）

对 n 进行从 2 到 n-1 的试除，若存在能整除的数则非质数。时间复杂度 O(n)。

#include 
        #include 

        bool is_prime_simple(int n) {
          if (n <= 1) return false;
          for (int i = 2; i < n; i++) {
            if (n % i == 0) return false;
          }
          return true;
        }

        int main(void) {
          printf("%d\n", is_prime_simple(97));   /* 1 表示 true */
          printf("%d\n", is_prime_simple(100));  /* 0 表示 false */
          return 0;
        }

三、优化：只需试除到 sqrt(n)

若 n 有一个因子 a ≤ b 且 a*b = n，则 a ≤ sqrt(n)。因此只需检查到 sqrt(n)。复杂度 O(sqrt(n))。

#include 
        #include 

        bool is_prime_sqrt(int n) {
          if (n <= 1) return false;
          if (n == 2) return true;
          if (n % 2 == 0) return false;
          for (int i = 3; i * i <= n; i += 2) {
            if (n % i == 0) return false;
          }
          return true;
        }

        int main(void) {
          printf("%d\n", is_prime_sqrt(97)); /* 1 */
          return 0;
        }

四、更高阶：Miller–Rabin（随机化，大数常用）

对大整数判断质数，可使用 Miller–Rabin 作为概率性测试，或结合确定性基对常用上限。

练习题

  1. 实现一个函数返回小于等于 N 的质数数量（素数计数）。
  2. 用线性筛（Euler 筛）实现 1..N 的素数列表。
  3. 对大于 10^9 的数，尝试用 Miller–Rabin 验证质数性并讨论误判概率。
